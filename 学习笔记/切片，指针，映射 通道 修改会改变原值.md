- 在 Go 语言中，这是一个非常核心的内存与数据传递概念。为了让你一目了然，我为你把 Go 中“修改副本会直接改变原值”**的类型（即底层共享数据的类型）和**“不会改变原值”的纯值类型做了一个系统梳理：

  ### 一、 核心对比表：修改会改变原值 vs 不会改变原值

  | **类型分类**     | **具体类型**                              | **赋值 / 传参时的行为**      | **修改副本是否影响原值？** | **底层核心原因**                 |
  | ---------------- | ----------------------------------------- | ---------------------------- | -------------------------- | -------------------------------- |
  | **共享底层数据** | **指针 (`\*T`)**                          | 复制内存地址                 | **会影响**                 | 直接操作同一块内存空间           |
  | **共享底层数据** | **切片 (`[]T`)**                          | 复制切片头（指针、长、容）   | **会影响**（改元素时）     | 多个切片指向同一个底层数组       |
  | **共享底层数据** | **映射 (`map`)**                          | 复制指针（指向内部 `hmap`）  | **会影响**                 | 多个 map 变量指向同一个哈希表    |
  | **共享底层数据** | **通道 (`chan`)**                         | 复制指针（指向内部 `hchan`） | **会影响**                 | 多个变量操作同一个通信管道       |
  | **独立复制**     | **基础类型** (`int`, `string`, `bool` 等) | 完整复制数值                 | **不会影响**               | 拥有完全独立的存储空间           |
  | **独立复制**     | **数组 (`[N]T`)**                         | 完整复制所有元素             | **不会影响**               | 数组是严格的值类型，拷贝整块数据 |
  | **独立复制**     | **纯基础字段结构体**                      | 完整复制所有字段             | **不会影响**               | 结构体整体是值类型               |

  ### 二、 逐个剖析：“修改会改变原值”的四大主力

  #### 1. 指针 (Pointer - `*T`)

  - **表现**：将指针赋值给新变量或传给函数后，通过 `*ptr = 新值` 修改，原变量随之改变。
  - **原理**：指针存储的是变量的**内存地址**。复制指针只是复制了“门牌号”，两个指针指向的是同一间“房间”。

  #### 2. 切片 (Slice - `[]T`)

  - **表现**：将切片赋值给新切片（`s2 := s1`），修改 `s2[0] = 新值`，`s1[0]` 也会变。
  - **原理**：切片在底层是一个很小的结构体描述符（包含：底层数组指针、长度、容量）。复制切片时，复制的是这个描述符，它们共同指向**同一个底层数组**。因此修改元素会影响原数组。
  - *注*：如果通过 `append` 导致切片底层数组触发扩容（重新分配内存），则会切断共享关系。

  #### 3. 映射 (Map - `map[K]V`)

  - **表现**：把 map 赋给新变量或传参后，修改、添加或删除键值对，原 map 同步改变。
  - **原理**：Go 的 map 变量本质上是一个**指向底层哈希表结构体（`hmap`）的指针**。复制 map 变量只是复制了指针，大家操作的是同一个哈希表。

  #### 4. 通道 (Channel - `chan T`)

  - **表现**：把 channel 传递给多个 Goroutine，大家都可以向里面发送或接收数据。
  - **原理**：channel 在底层同样是一个**指针**（指向 `hchan` 结构体）。复制 channel 变量只是复制了引用，多个变量共享同一个通信管道。

  ### 三、 ⚠️ 特别注意：包含上述类型的结构体 (Struct)

  - **纯结构体**本身是值类型（整体赋值或传参会完整拷贝一份）。
  - 但如果**结构体内部包含了切片、指针、map 或 chan 字段**，当你复制这个结构体时，这些特殊字段所指向的底层数据依然会被共享。
  - **典型后果**：修改结构体副本里的切片元素，原结构体对应的切片也会被跟着改变！
