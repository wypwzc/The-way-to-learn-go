Go 语言在**代码组织、可见性控制（封装）以及命名规范**上最核心的几条铁律。

函数首字母大写：公共访问

函数首字母小写：私有的





- **“一个目录中的所有源文件必须共用同一个包名”**：在 Go 语言中，文件夹和包名有着强对应的关系。同一个文件夹下的所有 `.go` 文件，其开头的 `package xxx` 必须完全一致（通常文件夹名字也会和包名保持一致，但不是强制的）。
- **特殊包名 `main`**：如果是程序的入口包，包名必须是 `package main`，并且其中必须包含 `main()` 函数。



- **首字母大写（PascalCase，如 `Good`、`OrderInfo`）**：类似于 `public`，可以被外部包访问。
- **首字母小写（camelCase，如 `quantity`、`settleAccount`）**：类似于 `private`，只能在当前包内部访问，包外无法调用或修改。*(注：你之前代码中的 `iPhone`、`Phone` 因为是大写开头，所以外部可以引用；而像 `name`、`quantity` 如果首字母变大写，外部也能直接访问，小写则只能在结构体内部或同包内使用。)*

 命名风格建议

- **局部 / 内部使用**：`camelCase`（小驼峰命名法），例如 `calculateAllPrice`、`allPrice`。
- **跨包访问（公开）**：`PascalCase`（大驼峰命名法，也叫帕斯卡命名法），例如 `Good`、`Println`、`Itoa`。







### 报过的错

1. **常量定义**：在函数外部不能使用短变量声明 `:=`，应该用 `const` 关键字定义常量。
2. **函数返回值**：在 Go 中，不能直接把计算结果赋值给函数名（例如 `RemainingOvenTime = ...`），需要直接使用 `return` 返回。

~~~go
func RemainingOvenTime(actualMinutesInOven int) int {
	return OvenTime - actualMinutesInOven
}
~~~
