# Go（Golang）实际上**只有 25 个关键字（Keywords）**，这是 Go 语言设计简洁的重要体现。

下面按照功能分类来讲解，每个关键字都会说明作用并给出示例。

------

# 一、程序声明（4个）

## 1. package

声明当前文件属于哪个包。

```
package main
```

所有 Go 文件第一行都必须声明 package。

------

## 2. import

导入包。

```
import "fmt"
```

多个包：

```
import (
    "fmt"
    "time"
)
```

------

## 3. func

声明函数。

```
func hello() {
    fmt.Println("Hello")
}
```

main 函数：

```
func main() {

}
```

------

## 4. var

声明变量。

```
var name string
```

或者

```
var age = 20
```

------

# 二、类型声明（4个）

## 5. type

定义新的类型。

```
type User struct {
    Name string
}
```

也可以定义别名：

```
type MyInt int
```

------

## 6. struct

定义结构体。

```
type Student struct {
    Name string
    Age int
}
```

```go
// 定义结构体类型 User
type User struct {
	name   string
	age    int
	height float64
}

func main{
	var user1 User
	user1 = User{
		name:   "王亚鹏",
		age:    21,
		height: 1.76,
	}

	fmt.Println(user1)
	fmt.Println(user1.name)
}
```



------

## 7. interface

定义接口。

```go
type 接口名 interface {
    方法名1(参数) 返回值
    方法名2(参数) 返回值
}

```

------

## 8. map

声明 map 类型。

```
var m map[string]int
```

初始化：

```
m := make(map[string]int)
```

------

# 三、流程控制（8个）

## 9. if

条件判断。

```
if age > 18 {
    fmt.Println("Adult")
}
```

------

## 10. else

否则。

```
if ok {
    ...
} else {
    ...
}
```

------

## 11. switch

多分支判断。

```
switch day {
case 1:
    fmt.Println("Mon")
case 2:
    fmt.Println("Tue")
default:
    fmt.Println("Other")
}
```

------

## 12. case

switch 的分支。

```
case 1:
```

------

## 13. default

默认分支。

```
default:
```

------

## 14. for

Go 唯一的循环。

```
for i := 0; i < 10; i++ {
}
```

while：

```
for x < 10 {
}
```

死循环：

```
for {
}
```

------

## 15. range

遍历数组、切片、map、字符串、channel。

```
nums := []int{1,2,3}

for i,v := range nums{
    fmt.Println(i,v)
}
```

------

## 16. goto

跳转。

```
goto END

END:
fmt.Println("结束")
```

实际开发基本不用。

------

# 四、跳转控制（3个）

## 17. break

退出循环。

```
for {
    break
}
```

------

## 18. continue

继续下一次循环。

```
for i:=0;i<10;i++{
    if i==5{
        continue
    }
}
```

------

## 19. fallthrough

switch 中继续执行下一个 case。

```
switch n {
case 1:
    fmt.Println(1)
    fallthrough
case 2:
    fmt.Println(2)
}
```

输出

```
1
2
```

------

# 五、并发（2个）

Go 最大特色。

## 20. go

启动 Goroutine。

```
go hello()
```

立即开启一个新的协程。

------

## 21. chan

声明 Channel。

```
var ch chan int
```

初始化：

```
ch := make(chan int)
```

发送：

```
ch <- 10
```

接收：

```
x := <-ch
```

------

# 六、延迟、异常（3个）

## 22. defer

函数结束时执行。

```
defer fmt.Println("结束")
```

常用于关闭文件。

```
defer file.Close()
```

------

## 23. return

返回。

```
return
```

或者

```
return result
```

------

## 24. select

Channel 多路复用。

```
select {
case msg := <-ch1:
    fmt.Println(msg)
case msg := <-ch2:
    fmt.Println(msg)
}
```

专门用于 Channel。

------

# 七、其它（1个）

## 25. const

声明常量。

```
const PI = 3.14
```

也可以：

```
const (
    A = 1
    B = 2
)
```

------

# Go 25 个关键字总表

| 分类     | 关键字                                                     |
| -------- | ---------------------------------------------------------- |
| 声明     | `package` `import` `func` `var`                            |
| 类型     | `type` `struct` `interface` `map`                          |
| 流程控制 | `if` `else` `switch` `case` `default` `for` `range` `goto` |
| 跳转控制 | `break` `continue` `fallthrough`                           |
| 并发     | `go` `chan`                                                |
| 函数控制 | `defer` `return` `select`                                  |
| 常量     | `const`                                                    |

------

## 注意：`range` 和 `map` 并不是 Go 的关键字

严格来说，**Go 官方定义的 25 个关键字如下**：

```
break      default      func         interface    select
case       defer        go           map          struct
chan       else         goto         package      switch
const      fallthrough  if           range        type
continue   for          import       return       var
```

虽然 `range` 和 `map` 在日常使用中常被当作语法元素理解，但它们**确实属于 Go 的关键字**，包含在官方关键字列表中。

------

## 学习建议

对于刚开始学习 Go 的你，可以按下面的优先级掌握：

1. **第一阶段（必须熟练）**：`package`、`import`、`func`、`var`、`const`、`if`、`for`、`return`
2. **第二阶段（数据类型）**：`type`、`struct`、`interface`、`map`、`range`
3. **第三阶段（函数与错误处理）**：`defer`、`switch`、`case`、`default`
4. **第四阶段（并发编程）**：`go`、`chan`、`select`
5. **最后了解即可**：`goto`、`fallthrough`、`break`、`continue`
